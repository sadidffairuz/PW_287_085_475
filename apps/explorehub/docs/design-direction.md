# Arah desain ExploreHub

## 1. Landing
Visual utama mengambil rasa dari referensi travel/adventure: fotografi besar, tipografi editorial, komposisi tidak terlalu simetris, dan warna pasir/oranye.

## 2. Scroll
Setelah hero, halaman berubah menjadi hijau hutan untuk memberi rasa alam Indonesia. Konten berupa kategori pengalaman, bukan dashboard SaaS.

## 3. Peta
Peta menjadi fitur inti. Saat pengguna menekan "Jelajahi Peta", mereka masuk ke halaman biru yang fokus pada pencarian lokasi, filter aktivitas, marker, dan lokasi pengguna.

## 4. Booking
Halaman booking menggunakan treatment biru seperti situs travel modern. Form menjadi fokus utama dan hasil submit menampilkan ringkasan sebelum diarahkan ke WhatsApp.

## 5. Pengembangan berikutnya
- Auth user / provider / admin
- Database jadwal dan ketersediaan
- Detail provider
- Wishlist
- Review
- Dashboard user
- Dashboard provider
- Admin management
