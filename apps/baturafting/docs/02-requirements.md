# Requirements — BatuRafting

## Functional
1. Pengguna dapat melihat daftar aktivitas.
2. Pengguna dapat melihat detail aktivitas.
3. Pengguna dapat memilih paket booking.
4. Pengguna dapat memilih tanggal dan jumlah peserta.
5. Sistem prototype menampilkan hasil simulasi ketersediaan/estimasi.
6. Admin nantinya dapat mengelola layanan, jadwal, dan booking.

## Non-functional
- Responsive pada desktop dan mobile.
- Navigasi mudah dipahami.
- Validasi input dasar.
- Struktur kode dipisahkan berdasarkan fungsi.
- Data sensitif tidak disimpan pada frontend.

## Catatan
Backend, database, authentication nyata, dan security lanjutan dikerjakan pada sprint berikutnya.
