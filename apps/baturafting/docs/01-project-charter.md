# Project Charter — BatuRafting

## 1. Informasi Proyek
- Nama: BatuRafting
- Jenis: Web application booking aktivitas wisata
- Target pengguna: wisatawan dan admin perusahaan
- Platform: web

## 2. Problem Statement
Informasi layanan, jadwal, kapasitas, dan proses reservasi aktivitas wisata perlu disajikan secara lebih terstruktur agar calon pelanggan dapat memahami pilihan aktivitas dan melakukan booking dengan lebih mudah.

## 3. Solusi
Membangun website satu perusahaan penyedia aktivitas wisata yang menampilkan layanan, jadwal, dan alur booking, serta menyediakan dashboard admin untuk pengelolaan data.

## 4. MVP
- Halaman publik
- Katalog/detail layanan
- Cek jadwal/ketersediaan
- Booking
- Riwayat/status booking
- Admin dashboard
- CRUD layanan dan jadwal
- Testing dan deployment

## 5. Out of Scope
- Marketplace multi-perusahaan
- Aplikasi mobile native
- Payment gateway nyata pada MVP awal
- AI recommendation
- Live tracking
- Integrasi transportasi

## 6. Sprint 02
Fokus pada JavaScript, DOM manipulation, event handling, dan minimal satu interaksi lengkap yang bermanfaat bagi pengguna.
